# 수학날개 앱

- 학생 앱: https://oh8299-art.github.io/app/ — 학생 코드 4자리로 내 숙제·테스트·자료 확인
- 숙제체크(원장님·선생님): https://oh8299-art.github.io/app/t/ — 원장님·선생님 코드로 들어가기

기록은 원장님 구글 계정의 Apps Script(구글 시트·드라이브)에 저장되고, 입력하는 즉시 반영됩니다.

- `config.js` — 구글 서버 주소
- `t/` — 숙제체크 앱
- `tools/Code.gs` — 구글 Apps Script 서버 코드 (OWNER_CODE 는 붙여 넣은 뒤 직접 바꾸기)
